Data and limitations

  • No account, analytics SDK, ad SDK or external nutrition API.
  • Food database values marked estimate/low are approximate. Restaurant recipes and raw-versus-cooked weights can differ substantially.
  • Reference sources for future verified expansion include ICMR-NIN Indian Food Composition Tables 2017 and USDA FoodData Central. The included starter values are not a verified bulk import of either database.
  • Offline app-shell support requires serving the app from localhost or HTTPS; opening index.html as a file does not enable service workers.
  • Browser storage can be cleared by the operating system/browser. JSON backups are essential for long-term ownership.
  • This PWA is not a native APK. It can be installed through a supported browser when hosted on HTTPS.
